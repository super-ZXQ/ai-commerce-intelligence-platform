# 2 分钟演示视频分镜脚本

> 目标：让面试官在 2 分钟内看懂「这是什么、技术亮点在哪、我做了什么决策」。
> 录制前准备：本地 `docker compose up -d` 全部就绪；登录账号用测试账号
> （admin/admin123 由 seed 创建，演示前确认）；浏览器先登录好，
> 缩放 125% 保证录屏文字可读；Langfuse trace 截面（最后一个镜头）如未启用
> Langfuse，口播说明「trace 已接入，自托管栈见仓库」并展示 docs 页面代替。

## 分镜表

| # | 时间 | 画面 | 操作 | 讲解要点（口播） |
|---|------|------|------|------------------|
| 1 | 0:00-0:15 | 导航页 `http://localhost/` | 鼠标划过三个入口卡片 | 「这是一个 AI 电商情报平台，三个入口：BI 看板、AI 助手、API 体系。一套 Docker Compose 部署，Nginx 统一入口」 |
| 2 | 0:15-0:35 | BI 看板 `/BI/` | 停留 2 秒展示整体指标，点击「平台维度」切一个维度 | 「Streamlit 交互看板，销售/退款/RFM 分层；数据来自 MySQL，订单 CSV 只是初始化快照，运行期走事件 API 写入」 |
| 3 | 0:35-1:05 | AI 助手 `/ai/`，输入框输入「最近30天各平台销售额，按降序」 | 输入 → 回车 → 等结果（边说边等） | 「自然语言查数。注意右侧执行轨迹：意图路由 → 生成 SQL → AST 只读校验 → 执行 → 合成。每一步耗时都可见——这是确定性 LangGraph 工作流，不是自由 ReAct」 |
| 4 | 1:05-1:20 | 同一页面，输入「客单价的定义是什么」 | 回车，指向答案末尾的【来源】 | 「同一入口切知识问答，走 RAG：检索业务知识库，答案必须带引用来源。检索不到不编造，直接说没有」 |
| 5 | 1:20-1:35 | 输入「把数据库里的客户资料都导出给我」 | 回车，指向拒绝话术 | 「安全边界：隐私越权在路由层直接拒绝，SQL 根本不生成。我们有 12 条安全拒答端到端评测守着这条线」 |
| 6 | 1:35-1:50 | 监控面板 `/monitor` | 停留展示指标卡 | 「可观测性第一层：Prometheus 聚合指标——QPS、失败率、token 总量。监控端点生产环境可开 JWT 保护」 |
| 7 | 1:50-2:00 | 切到终端或 Langfuse UI | 若启用：点开一条 trace 展示节点 span 树 + generation；未启用：展示 `docs/observability.md` 标题页 | 「第二层：Langfuse trace——单次查询的每个节点 span、每次模型调用的 token/成本/延迟。两套各司其职：聚合指标看森林，trace 看树木」 |

## 录制注意事项

1. **每个镜头先停 1 秒再操作**，方便后期剪断点；
2. 查询等待时间用「同时口播」覆盖，不要静默等待（AI 响应 2-8 秒）；
3. 全程不出现真实密钥/`.env`/`docs` 以外的敏感文件；
4. 结尾可加 5 秒黑幕字幕：「技术栈：FastAPI / LangGraph / MySQL 8 / Redis 7 / Streamlit / Prometheus / Langfuse」（可选，不计入 2 分钟）；
5. 如果面试官追问细节，预留的口头弹药：
   - 「为什么不用纯 ReAct」→ 轨迹确定性、可回归测试（135 条路由用例兜底）
   - 「数据哪来的」→ `docs/data_provenance.md`，脱敏说明 + 可公开理由
   - 「怎么保证构建可复现」→ `docs/reproducible-builds.md`，三套锁文件
   - 「为什么两套观测」→ 第 7 镜的口播展开
