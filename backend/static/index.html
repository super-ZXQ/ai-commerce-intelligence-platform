SQL 安全的四道防线

LLM 生成的每一条 SQL，都必须活着通过这四层才会碰到数据。

LAYER 1

输入规则

input_safety 节点先跑正则与关键词规则，DROP/DELETE/UPDATE 等危险意图在进入 LLM 之前直接拒绝。

LAYER 2

AST 白名单

validate_sql 用 SQLGlot 解析语法树，只允许 SELECT；自动补 LIMIT 500，注入 MAX_EXECUTION_TIME(10000)。

LAYER 3

执行拦截器

SQLAlchemy 事件拦截器在执行前二次检查语句类型，失败最多重试 1 次，超限即返回结构化错误。

LAYER 4

只读账号

数据库账号本身只有只读权限——即使前三层全部失守，写操作在 MySQL 层也会被拒绝。

评测是断言结果集，不是感觉

端到端评测对查询结果集做断言（行数、列、关键值），而非检查「回答读起来对不对」。
